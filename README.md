# Redux Toolkit

A collection of code examples exploring Redux Toolkit and state management in JavaScript applications.

## About

A hands-on learning repository exploring Redux Toolkit, focusing on managing application state using slices, configuring Redux stores, handling asynchronous operations, and working with middleware.

The examples use cake and ice cream state management scenarios to explore Redux concepts, along with user-related state and asynchronous thunk logic.

## Topics Covered

- **Store Configuration** — setting up Redux stores using `configureStore`
- **Slices** — defining state, reducers, and generated actions using `createSlice`
- **Feature-Based State Management** — organizing state logic into cake, ice cream, and user features
- **Multiple Store Configurations** — experimenting with different store setups
- **Middleware** — integrating middleware into the Redux store
- **Asynchronous Operations** — handling asynchronous logic with `createAsyncThunk`
- **Extra Reducers** — handling actions and asynchronous thunk lifecycle states outside a slice's own reducers
- **State Management Patterns** — exploring how different features and reducers work together


## Getting Started

### Prerequisites

- Node.js
- npm
- Basic knowledge of JavaScript and Redux fundamentals

### Clone the Repository

```bash
git clone https://github.com/naba93980/redux-toolkit.git
cd redux-toolkit
```

### Install Dependencies

```bash
npm install
```

Explore the JavaScript files under `app/` and `features/` to understand the different store configurations, slices, middleware, and asynchronous state management examples.

Use the scripts defined in `package.json` to run the examples, if provided.

## Purpose

This repository serves as a practical reference for understanding Redux Toolkit and its core state management patterns through small, focused code examples.
